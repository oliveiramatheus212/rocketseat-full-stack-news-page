# 📰 News Page

Projeto desenvolvido como atividade prática da **formação Fullstack da Rocketseat**, com o objetivo de construir uma **página de notícias** moderna, organizada e visualmente atrativa utilizando **HTML** e **CSS**.

## ✨ Sobre o projeto

A proposta deste projeto é simular a interface de um portal de notícias com foco em:

- organização de conteúdo em seções
- hierarquia visual das informações
- estruturação semântica com HTML
- estilização com CSS moderno
- uso de variáveis para manter consistência visual

A página apresenta áreas de destaque como:

- notícias principais
- mais lidas da semana
- destaques sobre inteligência artificial
- barra de navegação e conteúdo lateral

## 🛠️ Tecnologias utilizadas

- `HTML5`
- `CSS3`
- `CSS Grid`
- `Google Fonts`

## 📁 Estrutura do projeto

```bash
news/

├── assets/
│   ├── icons/
│   └── images/
└── styles/
    ├── global.css
    ├── header.css
    ├── index.css

    └── utility.css
```

## 🚀 Como executar

Como este é um projeto estático, basta abrir o arquivo `index.html` no navegador.

### Opção 1

- clique duas vezes em `index.html`

### Opção 2

- use a extensão **Live Server** no VS Code para visualizar o projeto localmente
